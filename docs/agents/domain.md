# Domain Docs

Single-context repo: one `GLOSSARY.md` and `docs/adr/` at the repo root.

- Before exploring, read `GLOSSARY.md` and the ADRs that touch the area you work in.
- Name domain concepts as `GLOSSARY.md` defines them. A missing term is a gap to note for `/domain-modeling`, not a reason to invent a synonym.
- If your output contradicts an ADR, say so explicitly instead of silently overriding it.
